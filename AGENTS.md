# Repository rules

- Write AI-facing instructions, rules, and other content intended primarily for AI agents in English whenever practical.
- Do not add or retain documentation files. Keep only the minimal repository instruction files required for development.
- Do not write unnecessary comments. Explain non-obvious behavior through clear code and names.
- Commit changes at sensible checkpoints, keeping commits focused on one task or feature.
- Create a new branch for each task or feature before making changes.
